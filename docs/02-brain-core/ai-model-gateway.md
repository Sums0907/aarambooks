# Model Gateway

## 1. Purpose

The Model Gateway defines the abstraction boundary between Brain Core
intelligence capabilities and underlying intelligence providers.

Its purpose is to ensure Brain Core capabilities remain independent from
specific intelligence technologies.

The foundational rule is:

> Business systems create truth. Aaram Brain creates intelligence from
> that truth.

## 2. Responsibility

The Model Gateway provides:

-   Intelligence capability abstraction.
-   Provider independence.
-   Capability consistency.

## 3. Boundaries

The Model Gateway does not define:

-   AI provider selection.
-   Infrastructure decisions.
-   Deployment architecture.

## 4. Final Statement

The Model Gateway protects Brain Core evolution by separating
intelligence capabilities from underlying implementations.
