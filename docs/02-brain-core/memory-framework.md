# Memory Framework

## 1. Purpose

The Memory Framework defines how Aaram Brain retains
intelligence-related understanding while maintaining clear boundaries
from business truth.

Memory supports intelligence improvement.

It does not become a duplicate business record system.

The foundational rule is:

> Business systems create truth. Aaram Brain creates intelligence from
> that truth.

Aaram owns the Memory Framework semantics and logical structures. External or replaceable providers may be used for the underlying database, session, and cache infrastructure.

## 2. Memory Categories

### Knowledge Memory

Long-term ecosystem understanding.

### Interaction Memory

Understanding from previous intelligence interactions.

### Experience Memory

Patterns derived from previous situations and outcomes.

## 3. Boundaries

Memory must not:

-   Replace business databases.
-   Own operational history.
-   Modify domain truth.

## 4. Final Statement

Memory enables continuity of intelligence while preserving business
system authority.
