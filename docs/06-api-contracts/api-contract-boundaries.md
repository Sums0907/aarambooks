# API Contract Boundaries

## Purpose

Contract boundaries define where collaboration begins and ownership ends.

## Business System Boundary

Business systems own:

- Operational processes.
- Domain rules.
- Business truth.

## Brain Boundary

Aaram Brain owns:

- Understanding.
- Reasoning.
- Intelligence generation.

It does not own operational truth.

## Intelligence Domain Boundary

Intelligence domains own:

- Domain-specific intelligence logic.
- Problem-solving approaches.
- Intelligence outcomes.

## Application Boundary

Intelligence applications consume outcomes and create user-facing experiences.

## Final Rule

Contracts connect boundaries.

They do not remove boundaries.
