# docs/claude

Documentation, reviews, and written analysis produced by **Claude Code**.

This repo is worked on by two AI agents in parallel:

- **Gemini Pro** (Antigravity IDE) — bulk implementation. Its session transcripts are committed
  at `docs/ag_chat_*.md`.
- **Claude Code** — senior engineering work: architectural review, design decisions, hard
  debugging, code review, go/no-go calls. Its written output lands here.

Anything in this folder is review or analysis, not specification. Where it disagrees with
`docs/01-architecture/` or `docs/09-decisions/`, those remain authoritative.
